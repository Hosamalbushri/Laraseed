# Laraseed Generator V3 — Blade Components Reference

This document provides a comprehensive component reference for all Blade UI components generated by the **Web Starter Template** in Laraseed Generator V3.

All components are registered as anonymous Blade components under the package namespace:  
`<x-{{ PACKAGE_KEY }}_web::...>`

---

| Component Tag | Source Stub | Purpose |

## 2. Detailed Component Reference

---

### 1. Container (`<x-{pkg}_web::container>`)

Provides responsive horizontal padding and maximum width constraint (`max-w-7xl`).

#### Properties
*This component has no explicit `@props` declarations.*

#### Slots
- **Default (`$slot`):** Child content placed inside the container.

#### Attribute Forwarding
All HTML attributes passed to the component (e.g. `class`, `id`) are merged with the base classes:
`mx-auto max-w-7xl px-4 sm:px-6 lg:px-8`

#### Accessibility & RTL
Inherits document directionality. Uses symmetrical horizontal padding (`px-4 sm:px-6 lg:px-8`) which renders identically in both RTL and LTR modes.

#### Valid Blade Usage
```blade
<x-acme_portal_web::container class="py-12">
    <h1 class="text-3xl font-bold">Welcome to Our Portal</h1>
</x-acme_portal_web::container>
```

---

### 2. Section (`<x-{pkg}_web::section>`)

Wraps major page sections with responsive vertical padding and an optional centered heading area.

#### Properties
| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string|null` | `null` | Primary section heading (`<h2>`). |
| `subtitle` | `string|null` | `null` | Secondary explanatory text below title. |
| `description` | `string|null` | `null` | Alias for `subtitle`. |

#### Slots
- **Default (`$slot`):** Section body content rendered inside an internal `<x-container>`.

#### Attribute Forwarding
Merged with the root `<section>` element base classes: `py-12 sm:py-16 lg:py-20`.

#### Accessibility & Theme Behavior
- Headings are semantic `<h2>` elements with high-contrast text (`text-gray-900 dark:text-white`).
- Text automatically switches to muted grey in dark mode (`text-gray-600 dark:text-gray-300`).

#### Valid Blade Usage
```blade
<x-acme_portal_web::section
    title="Why Choose Us"
    subtitle="Engineered for speed, security, and scalability."
    class="bg-gray-50 dark:bg-gray-900/50"
>
    <div class="grid grid-cols-1 md:grid-cols-3 gap-6">
        <!-- Feature Cards -->
    </div>
</x-acme_portal_web::section>
```

### 3. Card (`<x-{pkg}_web::card>`)

Surface container supporting light/dark theme backgrounds, rounded corners, and hover elevation.

#### Properties
| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string|null` | `null` | Card title (`<h3>`). |
| `subtitle` | `string|null` | `null` | Explanatory subheadline text. |
| `description` | `string|null` | `null` | Alias for `subtitle`. |

#### Slots
- **Default (`$slot`):** Main card body content.

#### Attribute Forwarding
Merged with root card `<div>`:
`rounded-2xl border border-gray-200 bg-white p-6 shadow-sm transition-all hover:shadow-md dark:border-gray-800 dark:bg-gray-900`

#### Valid Blade Usage
```blade
<x-acme_portal_web::card title="System Status" subtitle="Updated every 5 minutes">
    <div class="flex items-center gap-2">
        <span class="h-3 w-3 rounded-full bg-green-500"></span>
        <span class="text-sm font-semibold">All Systems Operational</span>
    </div>
</x-acme_portal_web::card>
```

### 4. Button (`<x-{pkg}_web::button>`)

Polymorphic interactive component rendering an `<a>` anchor when `:href` is provided, or a `<button>` otherwise.

#### Properties
| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `string` | `'primary'` | Visual style: `'primary'`, `'secondary'`, `'outline'`, `'danger'`. |
| `size` | `string` | `'md'` | Button size: `'sm'`, `'md'`, `'lg'`. |
| `href` | `string|null` | `null` | URL target. If provided, renders an `<a>` tag. |
| `type` | `string` | `'button'` | Native button type (`'button'`, `'submit'`, `'reset'`). |

#### Variant Classes
- `primary`: `bg-[var(--brand-color)] text-white hover:opacity-90 focus:ring-[var(--brand-color)]`
- `secondary`: `bg-gray-100 text-gray-800 hover:bg-gray-200 dark:bg-gray-800 dark:text-gray-200`
- `outline`: `border border-gray-300 bg-transparent text-gray-700 hover:bg-gray-50 dark:border-gray-700 dark:text-gray-300`
- `danger`: `bg-red-600 text-white hover:bg-red-700 focus:ring-red-500`

#### Valid Blade Usage
```blade
<!-- Submit Button -->
<x-acme_portal_web::button variant="primary" size="md" type="submit">
    Save Profile
</x-acme_portal_web::button>

<!-- Navigation Link -->
<x-acme_portal_web::button
    :href="route('acme_portal.web.pages.show', ['page' => 'pricing'])"
    variant="outline"
    size="sm"
>
    View Pricing Plans
</x-acme_portal_web::button>
```

### 5. Modal (`<x-{pkg}_web::modal>`)

Accessible popup dialog with backdrop overlay, dismiss button, and scoped DOM ID.

#### Properties
| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `id` | `string` | *(Required)* | DOM ID used to open and close the modal. |
| `title` | `string|null` | `null` | Modal header title. |

#### Slots
- **Default (`$slot`):** Modal dialog body.

#### Accessibility Behavior
- Includes `tabindex="-1"` and `aria-hidden="true"`.
- Dismiss button includes `aria-label="Close modal"`.
- Closes via client-side JavaScript by adding the `hidden` utility class.

#### Valid Blade Usage
```blade
<!-- Modal Component -->
<x-acme_portal_web::modal id="terms-modal" title="Terms & Conditions">
    <p class="text-sm text-gray-600 dark:text-gray-300">
        Please read these terms carefully before proceeding...
    </p>
</x-acme_portal_web::modal>

<!-- Trigger Button -->
<x-acme_portal_web::button
    onclick="document.getElementById('terms-modal').classList.remove('hidden')"
    variant="secondary"
    size="sm"
>
    Read Terms
</x-acme_portal_web::button>
```

### 6. Form Control Group (`<x-{pkg}_web::form.control-group>`)

Standardized form field wrapper providing label formatting, required asterisks, and automated validation error display.

#### Properties
| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `name` | `string|null` | `null` | Form input name. Used for `for=""` attribute and error resolution. |
| `label` | `string|null` | `null` | Visible text label above input. |
| `required` | `bool` | `false` | When true, renders a red asterisk (`*`). |

#### Slots
- **Default (`$slot`):** The `<input>`, `<select>`, or `<textarea>` element.

#### Error Handling Behavior
Automatically checks `isset($errors) && $errors->has($name)` and renders `<p class="text-xs text-red-600 dark:text-red-400 mt-1">` with `$errors->first($name)`.

#### Valid Blade Usage
```blade
<x-acme_portal_web::form.control-group name="email" label="Email Address" :required="true">
    <input
        type="email"
        name="email"
        id="email"
        value="{{ old('email') }}"
        class="w-full rounded-lg border border-gray-300 px-3 py-2 dark:bg-gray-800 dark:border-gray-700 dark:text-white"
        placeholder="user@example.com"
    />
</x-acme_portal_web::form.control-group>
```

## 3. Common Developer Mistakes & Anti-Patterns

| Mistake | Consequence | Correct Pattern |
| :--- | :--- | :--- |
| **Using un-namespaced tags** (e.g. `<x-button>`) | Causes Blade collision when other packages define `<x-button>`. | Always use `<x-{{ package_key }}_web::button>`. |
| **Hardcoding button colors in markup** | Breaks dynamic branding configured in `config/web.php`. | Use `variant="primary"` which binds to `var(--brand-color)`. |
| **Omitting `:required="true"` on mandatory fields** | Missing visual indicator for accessibility and UX. | Pass `:required="true"` to `<x-form.control-group>`. |
| **Triggering modal without target ID** | JavaScript syntax errors. | Ensure trigger `onclick` references the exact `id` prop passed to `<x-modal>`. |
