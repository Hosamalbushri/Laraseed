# Laraseed Generator V3 — Template Structure & Stubs Reference

This document provides an exhaustive, file-by-file audit and technical reference for the **Web Starter Template** (`starter`) in Laraseed Generator V3.

---

## 1. Template Catalog Architecture

Templates in Generator V3 are registered statically in `Laraseed\PackageGenerator\Templates\WebTemplateCatalog`.

### 1.1 Discovery & Selection Mechanism

When a developer runs `php artisan laraseed:make-web Vendor/Package --template={template_id}`:
1. The command queries `WebTemplateCatalog::get($templateId)`.
2. If `$templateId` is omitted, it defaults to `WebTemplateCatalog::defaultTemplateId()` (`'starter'`).
3. If an unregistered ID is supplied, `WebTemplateCatalog` throws a `PackageGenerationException` listing all available registered template IDs.
4. The catalog returns a structured array defining the template metadata and an associative map of `[ destination_file_path => stub_path ]`.

```php
// WebTemplateCatalog data structure
protected static array $templates = [
    'starter' => [
        'id' => 'starter',
        'name' => 'Web Starter',
        'description' => 'Standard Web Starter template with Blade components, Tailwind CSS, Cairo typography, Vue 3, and package-isolated routes.',
        'files' => [
            'package.json'                                              => 'templates/starter/package.json.stub',
            'vite.config.js'                                            => 'templates/starter/vite.config.js.stub',
            // ... 29 mapped files
        ],
    ],
];
```

> [!NOTE]
> The template catalog is an explicit, programmatic registry. It does not perform dynamic filesystem scanning. Adding a new template requires defining its stubs under `stubs/templates/{id}/` and declaring its file mappings in `WebTemplateCatalog::$templates`.

## 2. Template Placeholders Reference

During stub processing, `WebGenerator` and `StubRenderer` substitute the following placeholders:

| Placeholder | Description | Example for `Acme/BlogPortal` |
| :--- | :--- | :--- |
| `{{ VENDOR }}` | Raw vendor name | `Acme` |
| `{{ PACKAGE }}` | Raw package name | `BlogPortal` |
| `{{ NAMESPACE }}` | Full PHP namespace | `Acme\BlogPortal` |
| `{{ ESCAPED_NAMESPACE }}` | Double-escaped PHP namespace | `Acme\\BlogPortal` |
| `{{ VENDOR_LOWER }}` | Lowercase vendor | `acme` |
| `{{ PACKAGE_KEBAB }}` | Kebab-case package name | `blog-portal` |
| `{{ PACKAGE_SNAKE }}` | Snake-case package name | `blog_portal` |
| `{{ PACKAGE_ID }}` | Laraseed package ID | `blog_portal` |
| `{{ PACKAGE_KEY }}` | Unique package identifier key (`vendor_package`) | `acme_blog_portal` |
| `{{ UPPER_PACKAGE_KEY }}` | Uppercase package key | `ACME_BLOG_PORTAL` |
| `{{ PACKAGE_SLUG }}` | URL/Directory slug (`vendor-package`) | `acme-blog-portal` |
| `{{ PACKAGE_TITLE }}` | Human-readable headline title | `Blog Portal` |
| `{{ COMPOSER_NAME }}` | Composer package name | `acme/blog-portal` |
