## 1. Overview & Objectives Achieved

In milestone **G03**, we enhanced the Web Package Generator with an extensible template selection mechanism while preserving lightweight, zero-database architecture.

Key features implemented:
- **CLI Option `--template`:** Added `--template=starter` to `php artisan laraseed:make-web`. Defaults to `starter` when omitted.
- **Template Registry (`WebTemplateCatalog`):** Introduced a clean catalog separating template metadata, stub mappings, and generator infrastructure without complex inheritance trees.
- **Strict Validation:** Rejects unknown template names immediately (e.g. `--template=unknown`) with an actionable error listing available templates.
- **Starter Template Isolation:** Grouped all starter template stubs under `packages/Laraseed/PackageGenerator/stubs/templates/starter/`.
- **Config & Route Caching Compatibility:** Verified that package configuration and route namespaces work seamlessly under Laravel's configuration caching (`config:cache`).

## 3. Developer Guide: Using the Web Package Generator

### A. Creating and Activating a Web Package

1. **Scaffold the base package (if not already created):**
   ```bash
   php artisan laraseed:make-package Acme/Portal
   ```

2. **Generate the Web capability using the Starter template:**
   ```bash
   # Default (uses starter):
   php artisan laraseed:make-web Acme/Portal

   # Explicit template flag:
   php artisan laraseed:make-web Acme/Portal --template=starter

   # Dry-run mode:
   php artisan laraseed:make-web Acme/Portal --template=starter --dry-run
   ```

3. **Activate the package in the application:**
   In `.env` or application environment:
   ```dotenv
   LARASEED_OPTIONAL_PACKAGES=portal
   ```

### B. Building Package Assets

Navigate to the generated package directory and build production assets:
```bash
cd packages/Acme/Portal
npm run build
# OR
npx vite build
```

This generates compiled CSS and JavaScript into `public/acme-portal/web/build/` with a production `manifest.json`.

For development with hot module reloading:
```bash
cd packages/Acme/Portal
npm run dev
```

### C. Customizing Pages, Components, and Navigation

All files generated by `make-web` belong to the package and are fully editable:

- **Main Layout:** `src/Web/Resources/views/components/layouts/index.blade.php`
- **Header & Mobile Drawer:** `src/Web/Resources/views/components/layouts/header/index.blade.php`
- **Navbar Links:** `src/Web/Resources/views/components/layouts/header/navbar.blade.php`
- **Footer:** `src/Web/Resources/views/components/layouts/footer/index.blade.php`
- **Home Landing Page:** `src/Web/Resources/views/home/index.blade.php`
- **Content Pages:** `src/Web/Resources/views/pages/show.blade.php`
- **Translations:** `src/Web/Resources/lang/en/app.php` and `src/Web/Resources/lang/ar/app.php`
- **Vue App & Styles:** `src/Web/Resources/assets/js/app.js` and `src/Web/Resources/assets/css/app.css`

### D. Configuring Route Prefixes & Root Route (`/`) Ownership

In `packages/Acme/Portal/src/Web/Config/web.php`:
```php
return [
    'template' => 'starter',

    // Default route prefix: '/acme-portal'
    // To mount this package at root '/', change to empty string:
    'prefix' => '',

    'middleware' => ['web'],
    'auth_guard' => null,
];
```

*Root Route Conflict Protection:* If two packages simultaneously configure `prefix => ''`, the runtime throws a `\RuntimeException` during boot to prevent silent route overwrites.

## 4. How to Add New Templates in Future Phases

Adding a new template to `Laraseed/PackageGenerator` requires only two simple steps:

1. **Create template stubs:**
   Place the new template stubs under `packages/Laraseed/PackageGenerator/stubs/templates/{template_id}/`.

2. **Register template metadata in `WebTemplateCatalog`:**
   In `packages/Laraseed/PackageGenerator/src/Templates/WebTemplateCatalog.php`:
   ```php
   protected static array $templates = [
       'starter' => [ ... ],
       'landing' => [
           'id' => 'landing',
           'name' => 'Marketing Landing Page',
           'description' => 'Single page high-conversion marketing template.',
           'files' => [
               'src/Web/Providers/WebServiceProvider.php' => 'templates/landing/provider.php.stub',
               // ... destination => stub path mappings
           ],
       ],
   ];
   ```

No changes to generator commands or kernel bindings are required.
